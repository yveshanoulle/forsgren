# Scripts/ci_job_groups.txt

# Which Quality job runs which gate (forsgren#259, decision #260). One row per
# gate that does NOT run in the main job:
#
#   <job>|<label of the row in Scripts/gate_report_order.txt>
#
# Every gate this file does not list runs in the main job, so a new gate is in
# one job and never in none. Scripts/run_ci_phase.sh reads it (its optional
# fourth argument is the job) and is red when a label here is no row of the
# order file. The label must be the exact label of the order file; the phase
# comes from the order file. sfl.sh and FBP.sh run every row, this file or not.
# Scripts/test_quality_jobs.sh pins the rows below and quality.yml's jobs.
#
# The isolation jobs: the slowest gate that no other gate waits for (measured in
# forsgren#259, step 1). The git sandbox isolation SCOPE self-test stays in the
# main job: it is short. Since forsgren#425 the step summary isolation gate has
# its own job, below: together the two took 15 minutes (the git sandbox
# self-test 9 min 27 s, the step summary gate 4 min 15 s, the setup 1.5 min).
#
# SHARDS (forsgren#426). The git sandbox isolation self-test runs its git-using
# self-tests in two shards, one job each. A row may carry a third field, the
# arguments the job runs the gate with:
#
#   <job>|<label>|<args>
#
# so the same label may stand in several jobs, each with its own shard. The
# self-test takes --shard N/M and runs every M-th self-test of its sorted list
# (index modulo M), so every self-test runs in exactly one shard and a new one
# lands in one by itself; the runner records each row as `<label> (shard N/M)`,
# and Scripts/merge_quality_report.sh joins the shards into the gate's one row,
# red when a shard is red or reported nothing. Another long gate shards the
# same way: add its rows here with --shard, one job each, and the jobs in
# quality.yml (Scripts/test_quality_jobs.sh pins the jobs it knows).
isolation_1|git sandbox isolation self-test|--shard 1/2
isolation_2|git sandbox isolation self-test|--shard 2/2
#
# The summary job (forsgren#425): the step summary isolation gate alone, so it
